# Personal Finance & Investment Advisor

An intelligent financial guidance platform that helps users manage expenses, plan budgets, track financial goals, monitor investments, and make informed financial decisions.

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- JWT Authentication
- MySQL

### Frontend
- React
- Vite
- React Router
- Axios
- Context API

### AI & Machine Learning
- Gemini API
- RAG (Retrieval Augmented Generation)
- AI Agents
- Python
- FastAPI
- Machine Learning Models
